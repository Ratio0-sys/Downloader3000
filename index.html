📥 Установка

1 Установка yt-dlp

  1. Откройте папку с распакованными файлами
  2. В адресной строке проводника (сверху) сотрите всё и напишите cmd, нажмите Enter
  3. В открывшейся командной строке введите:
winget install --id=yt-dlp.yt-dlp -e

⏳ Дождитесь завершения установки (может занять некоторое время)

1.1 Установка FFmpeg (ВАЖНО!)

⚠️ FFmpeg обязателен для объединения видео и аудио!

Добавьте в корневую папку файл ffmpeg.exe:

  1. Скачайте FFmpeg: github.com/BtbN/FFmpeg-Builds
  2. Вам нужен релиз Auto-Build (например, ffmpeg-N-126060-g03dc244a69-win64-gpl)
  3. Скачайте архив и найдите внутри папку bin
  4. Извлеките ffmpeg.exe из папки bin в корневую папку проекта (туда же, где лежат .bat файлы)

2 Настройка путей в батниках

В каждом .bat файле нужно изменить пути к папкам на свои:

Файл Что менять
download Best.bat --output "D:\download video\Saveged\%%(title)s.%%(ext)s"
Sounds download.bat --output "D:\download video\Sounds\%%(title)s.%%(ext)s"
720p download.bat --output "D:\download video\Saveged\%%(title)s [720p].%%(ext)s"
1080p download.bat --output "D:\download video\Saveged\%%(title)s [1080p].%%(ext)s"

Примеры путей:

  • C:\Users\Имя\Videos\Saveged
  • C:\Downloads\Saveged
⚠️ Важно! Указанная папка ДОЛЖНА СУЩЕСТВОВАТЬ на вашем компьютере. Если её нет — создайте заранее!

3 Готово к использованию!

Теперь можно запускать любой батник двойным кликом:

  1. Запустите нужный .bat файл
  2. Вставьте ссылку на видео (с https://) и нажмите Enter
  3. Видео скачается в указанную папку с оригинальным названием

🧙‍♂️ Дополнительные советы

  • Для выхода из любого батника введите exit вместо ссылки
  • Если yt-dlp не найден — перезагрузите компьютер или установите вручную с официального сайта

Форматы файлов:

  • Видео → .mp4
  • Аудио → .mp3 (максимальное качество)

Особенности:

  • ✅ Названия сохраняются оригинальные (с русскими буквами и спецсимволами)
  • ✅ Для видео в 720p и 1080p в название добавляется пометка [720p] или [1080p]

⚠️ Возможные проблемы и их решение

Проблема Решение
'yt-dlp' не является внутренней или внешней командой Установите yt-dlp через winget или перезагрузите компьютер
ffmpeg не найден Убедитесь, что ffmpeg.exe лежит в корневой папке с батниками
Ошибка при скачивании Проверьте интернет-соединение и правильность ссылки
Русские буквы отображаются кракозябрами Сохраните батники в кодировке UTF-8 (Блокнот → Сохранить как → UTF-8)

🛠️ Технические детали (для гиков)

Используемые технологии:
  - yt-dlp
  - FFmpeg
  - Batch (Windows)

Команды:
  Макс. качество:
    -f "bestvideo[ext=mp4]+bestaudio[ext=m4a]/bestvideo+bestaudio/best"
    --merge-output-format mp4
  
  Аудио:
    -f "bestaudio[ext=m4a]/bestaudio"
    --extract-audio --audio-format mp3 --audio-quality 0
  
  720p:
    -f "bestvideo[height<=720][ext=mp4]+bestaudio[ext=m4a]/bestvideo[height<=720]+bestaudio/best[height<=720]"
  
  1080p:
    -f "bestvideo[height<=1080][ext=mp4]+bestaudio[ext=m4a]/bestvideo[height<=1080]+bestaudio/best[height<=1080]"
