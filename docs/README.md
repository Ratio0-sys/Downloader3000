# Сайт проекта

Здесь живёт страница <https://ratio0-sys.github.io/Downloader3000/>.

| Файл | Что это |
| --- | --- |
| `index.html` | сама страница, самодостаточная: стили внутри, внешних зависимостей нет |
| `screenshots/` | снимки интерфейса для страницы и README |
| `.nojekyll` | отключает Jekyll |

## Зачем нужен .nojekyll

Без него GitHub Pages прогоняет содержимое через Jekyll. Тот пытается
собрать сайт по своим правилам и в какой-то момент решает, что индексом
должен быть `README.md`, а не `index.html`. Разметку внутри блоков `<div>`
он при этом не обрабатывает, и на странице появляется сырой текст
вроде `# Заголовок` и `**жирный**`.

Пустой файл `.nojekyll` говорит: ничего не собирай, отдавай файлы как есть.

## Настройка на GitHub

**Settings → Pages → Source → Deploy from branch → ветка `main`, папка `/docs`**

Если оставить папку `/ (root)`, страница отдаст либо 404, либо
перемолотый README — `index.html` лежит не там.

## Правка страницы

Открыть `index.html` в браузере — он работает из файла, сервер не нужен.
Цвета вынесены в переменные в начале `<style>` и совпадают
с палитрой приложения из `src/app/theme.py`.
