Что умеет

  • Плейлисты по выбору. Ссылка на плейлист разворачивается в список с галочками. Отмечаете нужное — остальное не качается. Есть счётчик выбранного и суммарная длительность.
  • Два языка. Русский и английский, определяется по системе, переключается без перезапуска.
  • Три оформления. «Оригинал» с градиентом и стеклом, плоские «Тёмная» и «Светлая».
  • Масштаб интерфейса от 80 % до 150 % — если шрифт мелковат.
  • Честный прогресс. Скорость, оставшееся время, стадия работы и кнопка отмены, которая действительно отменяет.
  • Живой лог. Если что-то сломалось — видно, что именно, а не «ошибка, попробуйте позже».
  • Оригинальные названия файлов — с русскими буквами и спецсимволами, без транслита.

Для Android берите arm64-v8a — подходит почти всем телефонам последних лет. armeabi-v7a нужен только совсем старым.

О чём честно предупредить

Это не баги, а вещи, которые нельзя обойти.

Windows 7 и 8.1 не поддерживаются. Дело не в программе: движок yt-dlp требует Python 3.10 и новее, а он на эти системы не устанавливается в принципе. Официальные сборки самого yt-dlp тоже давно требуют Windows 10.
На Android нужен APK под свою архитектуру. Бинарники ffmpeg и QuickJS вшиты в сборки для arm64 и arm32 — это все настоящие телефоны. Под x86_64 их нет, поэтому в эмуляторе склейка видео и конвертация в MP3 работать не будут.

Почему ffmpeg вообще нужен

YouTube больше не отдаёт картинку и звук одним файлом — только раздельными потоками, которые нужно склеивать. Мы проверили это на живом ролике и получили 32 потока без звука, 11 без картинки и ни одного совмещённого. Поэтому в настольные сборки ffmpeg встроен: раньше его приходилось искать вручную, и это была главная причина, по которой у людей ничего не работало.

Запустить из исходников:

git clone https://github.com/Ratio0-sys/Downloader3000.git
cd Downloader3000

python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Linux / macOS

pip install -e "src[dev]"
python tools/fetch_quickjs.py
python src/main.py

Код прокомментирован по-русски: можно открыть любой файл и понять, что там происходит и почему именно так. Подробности — в CONTRIBUTING.md.
